# Qwen Olympiad Solver JS Module

Автономный JS-модуль для встраивания в веб-страницы. Позволяет автоматически решать тесты, задачи и олимпиадные задания с помощью локальной нейросети **Qwen** (через Ollama / LM Studio) без API-ключей и оплаты.

## 🚀 Особенности
- **Без API-ключа**: Работает через локальный инференс (`http://localhost:11434` или `http://localhost:1234`).
- **Floating UI**: Кнопка включения/выключения и управления встроена в нижний правый угол экрана.
- **Универсальный парсинг**: Решает выделенный текст или автоматически сканирует задания по CSS-селекторам.
- **Высокая скорость**: Никаких сторонних серверов и задержек сети.
