# Qwen Olympiad Solver Widget

Автономный JavaScript-модуль для встраивания на любые веб-страницы. Помогает решать олимпиады, тесты и задачи с помощью локальной нейросети **Qwen** (через Ollama или LM Studio) **без API-ключей и подписок**.

## Особенности
- **Без API-ключа**: Работает полностью локально на вашем компьютере.
- **Интерфейс внизу экрана**: Удобная плавающая кнопка управления в правом нижнем углу.
- **Работа с выделением**: Просто выделите текст задачи на странице — модуль отправит его в Qwen и покажет подробный ответ.
