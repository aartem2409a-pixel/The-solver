# 🤖 The Solver — Автономный модуль решения задач через локальную нейросеть Qwen

**The Solver** — это легкий и мощный JavaScript-модуль, который вшивается в любую веб-страницу (олимпиады, тесты, учебные порталы) и позволяет решать задачи с помощью локальной языковой модели **Qwen** (через **Ollama** или **LM Studio**).

Инструмент работает абсолютно бесплатно, без интернета, без сторонних серверов и без каких-либо API-ключей. Весь процесс расчёта происходит локально на вашем компьютере, обеспечивая максимальную скорость и конфиденциальность.

В правом нижнем углу экрана располагается удобная плавающая кнопка с индикатором статуса, открывающая компактную панель управления.

## ⚙️ Системные требования

*   **Операционная система:** Windows 10/11, macOS, Linux.
*   **ОЗУ (RAM):** От 8 ГБ (для моделей 7B рекомендуется от 16 ГБ свободной оперативной памяти или дискретная видеокарта с поддержкой аппаратного ускорения).
*   **Браузер:** Любой современный браузер (Google Chrome, Яндекс Браузер, Mozilla Firefox, Microsoft Edge, Safari).

## 🛠️ Пошаговая инструкция по установке

### Шаг 1. Установка и запуск локального сервера Ollama с поддержкой CORS

По соображениям безопасности современные браузеры блокируют прямые запросы веб-страниц к локальному компьютеру (политика CORS). Чтобы ваш браузер мог передавать текст задачи на локальный сервер, Ollama должна быть запущена с разрешением внешних источников (`*`).

1. Скачайте и установите [Ollama](https://ollama.com/) для вашей операционной системы.
2. Откройте Терминал (в macOS/Linux) или **PowerShell** (в Windows).
3. Запустите сервер со специальной переменной окружения, разрешающей междоменные запросы:

*   **Для Windows (в PowerShell):**

```powershell
    $env:OLLAMA_ORIGINS="*"
    ollama serve
```

*   **Для macOS / Linux (в Терминале):**

```bash
    export OLLAMA_ORIGINS="*"
    ollama serve
```

> ⚠️ **Важно:** Не закрывайте это окно терминала во время работы со скриптом, так как оно поддерживает локальный сервер активным.

### Шаг 2. Загрузка модели Qwen

Не закрывая первое окно терминала, откройте второе окно терминала (или вкладку) и загрузите модель `qwen2.5:7b` (или другую на ваш выбор, например `qwen2.5:3b` для более слабого железа):

```bash
ollama run qwen2.5:7b
```

Дождитесь завершения скачивания. Как только в терминале появится строка приглашения к вводу, модель готова принимать запросы. После этого второе окно терминала можно свернуть.

### Шаг 3. Подключение модуля к странице

У вас есть два варианта подключения модуля в зависимости от вашей задачи:

#### Способ А: Через консоль браузера (Самый быстрый и универсальный)

Этот способ идеально подходит для прохождения тестов и олимпиад на сторонних сайтах, где у вас нет постоянного доступа к исходному коду:

1. Откройте в браузере страницу с нужным заданием.
2. Нажмите клавишу **F12** (или кликните правой кнопкой мыши по фону страницы → *Исследовать элемент / Просмотреть код*).
3. Перейдите на вкладку **Console** (Консоль).
4. Скопируйте, вставьте следующий код и нажмите **Enter**:

```javascript
    const s = document.createElement('script');
    s.src = 'https://cdn.jsdelivr.net/gh/...'; // Замените на актуальную ссылку из вашего проекта
    document.body.appendChild(s);
```
    *(Примечание: на скриншоте ссылка обрезана, не забудьте вставить полный путь до вашего скрипта)*

#### Способ Б: Внедрение в HTML-код страницы

Если вы создаете собственный проект или имеете прямой доступ к исходникам сайта, вставьте эту строку прямо перед закрывающим тегом `</body>` в вашем HTML-файле:

```html
<script src="https://cdn.jsdelivr.net/gh/..."></script>
```

### Шаг 4. Использование интерфейса виджета

1. После успешного выполнения скрипта в правом нижнем углу экрана появится плавающая кнопка **«Qwen Solver: ON»**.
2. Зеленый кружок на кнопке означает, что модуль успешно связался с вашим локальным сервером Ollama. Если кружок горит красным — проверьте, запущен ли сервер из Шага 1.
3. Выделите мышкой текст задачи или вопроса прямо на странице.
4. Нажмите на кнопку виджета, чтобы открыть панель управления, и нажмите кнопку **«⚡ Решить выделенный текст»**.
5. Нейросеть мгновенно проанализирует условие и выведет в блоке ответов подробный разбор, логику решения и итоговый вердикт.

## ❓ Частые проблемы и решения (FAQ)

*   **Индикатор горит красным, а в панели отображается ошибка `Failed to fetch`:**
    *   Скорее всего, вы забыли запустить Ollama с обязательным параметром CORS (`$env:OLLAMA_ORIGINS="*"`). Перезапустите терминал и выполните команду заново.
*   **Модель выдает ошибку, что модель не найдена:**
    *   Убедитесь, что в поле настройки модели в панели виджета указано точное имя модели, которая установлена у вас на компьютере (например, `qwen2.5:7b`), и она успешно скачана (`ollama list`).
*   **Не получается выделить текст на защищенном сайте:**
    *   Некоторые учебные платформы блокируют выделение текста через CSS. Вы можете открыть вкладку *Elements* (Инспектор кода) по клавише F12, скопировать HTML-код задачи вручную или использовать консоль для извлечения текста.
