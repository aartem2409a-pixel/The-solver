# Qwen Olympiad Solver Widget

Автономный JavaScript-модуль для встраивания на любые веб-страницы. Помогает решать олимпиады, тесты и задачи с помощью локальной нейросети **Qwen** (через Ollama или LM Studio) **без API-ключей и подписок**.

## Особенности
- **Без API-ключа**: Работает полностью локально на вашем компьютере.
- **Интерфейс внизу экрана**: Удобная плавающая кнопка управления в правом нижнем углу.
- **Работа с выделением**: Просто выделите текст задачи на странице — модуль отправит его в Qwen и покажет подробный ответ.

## Подробная инструкция по установке и запуску (Пошагово)

Чтобы скрипт мог отправлять задачи в нейросеть, на вашем компьютере должен быть запущен локальный сервер искусственного интеллекта. Ниже приведена инструкция для связки с **Ollama**.

### Шаг 1. Установка и запуск Ollama с поддержкой CORS
По умолчанию браузеры блокируют запросы к локальным серверам из соображений безопасности (CORS). Чтобы разрешить странице обращаться к вашей модели, сервер нужно запустить с специальным параметром.

1. Установите [Ollama](https://ollama.com/), если еще не сделали этого.
2. Откройте терминал (командную строку) и запустите сервер с разрешенными источниками (`OLLAMA_ORIGINS="*"`):

   * **Для Windows (в PowerShell):**
     ```powershell
     $env:OLLAMA_ORIGINS="*"
     ollama serve
     ```
   * **Для macOS / Linux (в Терминале):**
     ```bash
     export OLLAMA_ORIGINS="*"
     ollama serve
     ```

### Шаг 2. Загрузка и запуск модели Qwen
Не закрывая первый терминал, откройте **второе окно терминала** и скачайте/запустите рекомендуемую модель (например, `qwen2.5:7b`):

```bash
ollama run qwen2.5:7b
