# 🤖 The Solver — Автономный модуль решения задач через локальную нейросеть Qwen

**The Solver** — это легкий и мощный JavaScript-модуль, который вшивается в любую веб-страницу (олимпиады, тесты, учебные порталы) и позволяет решать задачи с помощью локальной языковой модели **Qwen** (через **Ollama** или **LM Studio**). 

Инструмент работает **абсолютно бесплатно, без интернета, без сторонних серверов и без каких-либо API-ключей**. Весь процесс расчёта происходит локально на вашем компьютере, обеспечивая полную конфиденциальность.

В правом нижнем углу экрана располагается удобная плавающая кнопка с индикатором статуса, открывающая компактную панель управления.

## ⚙️ Системные требования

* **Операционная система**: Windows 10/11, macOS, Linux.
* **ОЗУ (RAM)**: От 8 ГБ (для моделей 7B рекомендуется от 16 ГБ свободного оперативной памяти или дискретная видеокарта с поддержкой CUDA/Metal).
* **Браузер**: Любой современный браузер (Google Chrome, Yandex Browser, Firefox, Edge).

## 🛠 Пошаговая инструкция по установке

### Шаг 1. Установка и запуск локального сервера Ollama с поддержкой CORS

По соображениям безопасности современные браузеры блокируют запросы веб-страниц к локальному компьютеру (политика CORS). Чтобы ваш браузер мог передавать текст задачи на локальный сервер, Ollama должна быть запущена с разрешением внешних источников (`*`).

1. Скачайте и установите [Ollama](https://ollama.com/) для вашей ОС.
2. Откройте **Терминал** (в macOS/Linux) или **PowerShell** (в Windows).
3. Запустите сервер со специальной переменной окружения:

   * **Для Windows (в PowerShell):**
     ```powershell
     $env:OLLAMA_ORIGINS="*"
     ollama serve
     ```
   * **Для macOS / Linux (в Терминале):**
     ```bash
     export OLLAMA_ORIGINS="*"
     ollama serve
     ```

> ⚠️ *Важно: Не закрывайте это окно терминала во время работы со скриптом, так как оно поддерживает локальный сервер активным.*
